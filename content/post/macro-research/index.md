# Macroeconomic and Statistical Modelling

[Macroeconomic Observatory](https://macro.cepremap.fr/) (Providing free and state-of-the-art tools for macroeconomic analysis: Dynare software, DBnomics database, and Policy analysis)

[The Macroeconomic Model Data Base](http://www.macromodelbase.com/) (The Macroeconomic Model Data Base is an archive of macroeconomic models based on a common computational platform that provides various tools for systematic model comparison. The project is headed by [Volker Wieland (Goethe University Frankfurt)](https://www.imfs-frankfurt.de/professuren/prof-volker-wieland.html))

[FRB/US Model](https://www.federalreserve.gov/econres/us-models-about.htm) (The FRB/US model is a large-scale estimated general equilibrium model of the U.S. economy that has been in use at the Federal Reserve Board since 1996)

[Univariate Distribution Relationships](http://www.math.wm.edu/~leemis/chart/UDR/UDR.html) (Graphical tool mapping the relationships between all major univariate probability distributions)

[Multilevel modeling & Panel regression with R, Stata, and SPSS](https://sites.google.com/view/statistics-for-the-real-world/contents/multilevel-modeling-and-panel-regression) (On-line statistical training and videos provided through the website Multivariate statistics for the real world by Mike Crowson, University of Oklahoma)

# Computation
## Matlab
Numerical computing and programming environment based on matrix manipulations developed by MathWorks, Inc.

- [Dynare](https://www.dynare.org/) (Dynare is a free software for handling a wide class of economic models, in particular dynamic stochastic general equilibrium (DSGE) and overlapping generations (OLG) models. Matlab is required in order to run Dynare. However, as an alternative, Dynare also runs with [Octave](https://www.gnu.org/software/octave/) (a free clone of Matlab)

- [Dynare Code and Documentation](https://sites.google.com/site/pfeiferecon/dynare) written by Johannes Pfeifer

- [VAR Analysis Toolbox](https://sites.google.com/site/ambropo/MatlabCodes) (A collection of Matlab codes to perform Vector Autoregression (VAR) analysis by Ambrogio Cesa-Bianchi)

- [Iris Macroeconomic Modeling Toolbox](https://iris.igpmn.org/) (Open-source toolbox for macroeconomic modeling and forecasting in Matlab)

- [CompEcon Toolbox for Matlab](https://pfackler.wordpress.ncsu.edu/compecon/154-2/) (CompEcon is a set of Matlab functions for solving a variety of problems in economics and finance developed to accompany [Applied Computational Economics and Finance, Mario J. Miranda & Paul L. Fackler, MIT Press](https://pfackler.wordpress.ncsu.edu/compecon/))

- [Code and Data for advanced SVAR](http://silviamirandaagrippino.com/code-data) by Silvia Miranda-Agrippino

## Julia
Python and Julia are two free general purpose programming languages for numerical and scientific computing in open source

Helpful Links on Computational Economics for Matlab, Python, and Julia:

- [Jupyter Notebook](https://jupyter.org/) (Open-source web application that allows you to create and share documents that contain live code, equations, visualizations and narrative text)

- [Quantitative Economics](https://quantecon.org/) web-based course spearheaded by John Stachurski and Thomas J. Sargent for quantitative economic modelling with Python and Julia

## Excel

- [Real-statistics.com](https://www.real-statistics.com/) (Templates and notes on how to effectively use Excel for statistical analysis)

- [AET Excel Utilities](http://dailydoseofexcel.com/archives/2015/04/03/aet-excel-utilities/) (Add-in for Excel that facilitates routine tasks)

- [Excel2Latex](https://github.com/krlmlr/Excel2LaTeX/releases) (Excel® add-in which converts the current selection from an excel file as LaTeX markup that can be imported into an existing LaTeX document)

- [FRED add-in](https://fred.stlouisfed.org/fred-addin/) (Excel® add-in that provides direct access through Excel® to macro data from Federal Reserve Bank of St. Louis Economic Data (FRED))

# Text Editing and Visualization

[LyX](https://www.lyx.org/) (LyX is a free document processor that combines TeX/LaTeX with a user-friendly graphical interface)

[Cite This For Me](https://www.citethisforme.com/) (Cite This For Me is an open-access generator to fully-format all of your citations (for Word): Chicago, APA, Harvard, ASA, etc.)

[EconGraphs](https://www.econgraphs.org/) (Intuitive interactive visualizations of key concepts in economics)

[CLARIFY](https://gking.harvard.edu/clarify) (CLARIFY is a free software for interpreting and presenting statistical results with Stata)

[Desmos](https://www.desmos.com/) (Fee online tool to graph functions, plot data, evaluate equations, explore transformations, etc.)

[Highcharts Cloud](https://app.everviz.com/create?redirected-from-hs) (Highcharts is an on-line tool to create interactive charts, free for non-commercial and personal use)

[mapchart.net](https://mapchart.net/) (mapchart.net helps you create customized maps of the World, Europe, and the United States)

[Acronym Finder](https://www.acronymfinder.com/) (Acronym Finder is the world's largest and most comprehensive dictionary of acronyms, abbreviations, and initialisms)

[Crossref](https://search.crossref.org/) (Search engine from Crossref: the official Digital Object Identifier (DOI) Registration Agency)

[connectedpapers](https://www.connectedpapers.com/) (Free online tool to explore connected academic papers in a visual network graph)
